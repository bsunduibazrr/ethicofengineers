# Амьдрал 3.0 — Макс Тегмарк

«Инженерийн ёс зүй» хичээлд зориулсан, Макс Тегмаркийн *Life 3.0* номын 1 ба 2-р бүлгийн танилцуулга (20 слайд, Next.js).

## Ажиллуулах

```bash
npm install
npm run dev   # http://localhost:3000
```

Илтгэгчийн нэрийг `deck.config.ts` файлд солино.

| Товч | Үйлдэл |
|---|---|
| ← → / Space | Слайд солих |
| F | Бүтэн дэлгэц |
| N | Илтгэгчийн тэмдэглэл, цаг |
